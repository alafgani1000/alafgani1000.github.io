Ringkasan Aplikasi

Quiz App adalah aplikasi untuk manajemen kuis yang dibuat menggunakan bahasa pemrograman PHP dengan framework Laravel. Aplikasi ini memiliki berbagai fitur seperti membuat kuis, menambahkan pertanyaan dan jawaban, serta mempublikasikannya ke halaman utama agar peserta dapat mengikuti sesi kuis setelah mendaftar.

Aplikasi ini bersifat open source dan gratis, sehingga siapa pun dapat memodifikasi dan mengembangkannya agar menjadi lebih baik serta menjadi media pembelajaran pengembangan aplikasi web modern.

Instalasi Aplikasi

Berikut langkah-langkah untuk menginstal aplikasi Laravel dari GitHub:

  1. Clone dari repositori: 
    git clone https://github.com/kuis-tech/quiz-app.git
cd quiz-app
  2. Salin file .env.example menjadi .env dan sesuaikan konfigurasi database (nama database, pengguna, dan kata sandi).
  3. Instal semua dependensi backend dan frontend: 
    composer install
npm install
  4. Buat kunci aplikasi dan siapkan database baru sesuai file .env, lalu jalankan migrasi & seeder: 
    php artisan key:generate
php artisan migrate
php artisan db:seed
  5. Jalankan build frontend dan server lokal: 
    npm run dev
php artisan serve
    Akses aplikasi di http://localhost:8000 dan masuk menggunakan kredensial dari UserSeeder.
