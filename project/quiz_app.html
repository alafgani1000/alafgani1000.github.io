Intro

Quiz App adalah aplikasi untuk manajemen kuis yang dibuat menggunakan bahasa pemrograman PHP, lebih spesifik dengan framework Laravel. Aplikasi ini memiliki berbagai fitur seperti membuat kuis, menambahkan pertanyaan dan jawaban, serta mempublikasikannya ke halaman utama. Setiap orang dapat mengakses dan mengikuti kuis tersebut, dengan syarat mereka harus mendaftar terlebih dahulu.

Aplikasi ini masih memiliki beberapa kekurangan, namun sudah cukup lengkap untuk fitur-fitur dasarnya. Selain itu, aplikasi ini bersifat open source atau gratis, sehingga siapa pun dapat mengubah dan mengembangkannya agar menjadi lebih baik serta memiliki lebih banyak fitur. Aplikasi ini juga dapat digunakan sebagai media pembelajaran bagi siapa pun yang sedang belajar coding, khususnya dalam pengembangan aplikasi berbasis web.

Kebutuhan Aplikasi

  • PHP ^8.1
  • Composer 2
  • Node.js 20+
  • NPM 10+
  • Mysql
  • Redis Server
  • Web Server (Apache, Nginx, etc.)

Instalasi App

Berikut langkah-langkah untuk menginstal aplikasi Laravel dari GitHub:
  1. Clone dari Repositori
    git clone https://github.com/kuis-tech/quiz-app.git
  2. Arahkan ke Direktori Proyek, apabila menggunakan command prompt gunakan perintah cd nama-folder.
  3. copy .env.example ganti nama dengan .env
  4. Konfigurasi File .env, sesuaikan pengaturan database seperti nama basis data, nama pengguna, dan kata sandi.
  5. Jalankan command composer install dan npm install untuk menginstal semua dependensi yang diperlukan.
  6. Jalankan command php artisan key:generate
  7. Siapkan basis data baru yang sesuai dengan nama yang ditentukan dalam file .env.
  8. Jalankan command php artisan migrate
  9. Jalankan perintah php artisan db:seed untuk input aturan awal.
  10. Jalankan perintah npm run dev atau yarn dev.
  11. Mulai Server Laravel: Luncurkan server dengan php artisan serve dan akses aplikasi di http://localhost:8000.
  12. Silakan masuk dengan nama pengguna dan kata sandi di UserSeeder.
