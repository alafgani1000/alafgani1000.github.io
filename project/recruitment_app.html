Ringkasan & Fitur Utama

Sistem manajemen rekrutmen berbasis Laravel dan React/Inertia.js untuk membantu perusahaan mengelola seluruh recruitment funnel dari pemasangan lowongan hingga undangan wawancara, sekaligus memudahkan pencari kerja melamar dengan CV tersimpan.

Untuk Perusahaan

  • Manajemen publikasi lowongan kerja.
  • Pelacakan pelamar dan tahapan seleksi (Skrining, Wawancara, Asesmen, Penawaran).
  • Penjadwalan wawancara dan profil perusahaan.

Pencari Kerja & Admin

  • Pencarian kerja dengan filter kategori, lokasi, dan tipe pekerjaan.
  • Pembuat CV dan pelacakan riwayat lamaran satu klik.
  • Admin: manajemen data master, pengguna, dan konfigurasi status seleksi.

Instalasi Aplikasi

Berikut langkah-langkah untuk menginstal aplikasi ini dari GitHub:

  1. Klon repositori 
    git clone https://github.com/alafgani1000/recruitment.git
cd recruitment
  2. Instal Dependensi Backend & Frontend 
    composer install
npm install
  3. Konfigurasi File Environment & App Key 
    cp .env.example .env
php artisan key:generate
    Perbarui konfigurasi database, mail driver, dan antrean pada file .env: 
    DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=Recruitment_db
DB_USERNAME=root
DB_PASSWORD=

QUEUE_CONNECTION=database
  4. Migrasi Database & Storage Link 
    php artisan migrate --seed
php artisan storage:link
  5. Menjalankan Aplikasi 
    # Terminal 1 (Backend)
php artisan serve

# Terminal 2 (Frontend)
npm run dev

# Queue Worker untuk email asinkron
php artisan queue:work
    Aplikasi tersedia di http://127.0.0.1:8000. Kredensial administrator seeder: email admin@test.com, password test.
