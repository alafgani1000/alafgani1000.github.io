Instalasi Aplikasi

Berikut langkah-langkah untuk menginstal aplikasi ini dari GitHub:

  1. Klon repositori 
    git clone https://github.com/alafgani1000/project-app.git
cd project-app
  2. Instal Dependensi PHP 
    composer install
  3. Instal Dependensi JavaScript 
    npm install
# atau
yarn install
  4. Konfigurasi Aplikasi
    • Salin file konfigurasi: 
      cp .env.example .env
    • Generate App Key: 
      php artisan key:generate
    • Konfigurasi database di .env: 
      DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=project_app
DB_USERNAME=root
DB_PASSWORD=
  5. Pengaturan Database & Penyimpanan 
    php artisan migrate --seed
php artisan storage:link
  6. Konfigurasi Email & Antrean (Queue) 
    MAIL_MAILER=smtp
MAIL_HOST=sandbox.smtp.mailtrap.io
MAIL_PORT=2525
MAIL_USERNAME=username_anda
MAIL_PASSWORD=password_anda
MAIL_ENCRYPTION=tls
QUEUE_CONNECTION=database
  7. Menjalankan Aplikasi 
    # Terminal 1 (Backend)
php artisan serve

# Terminal 2 (Frontend)
npm run dev

# Opsional: Queue Worker / Production Build
php artisan queue:work
npm run build

Panduan Pengguna

  1. Buat project baru lalu tentukan timeline dan anggota tim.
  2. Tambahkan task, assignee, prioritas, dan dependency.
  3. Gunakan board serta kalender untuk memantau progres harian.
  4. Cek dashboard health untuk melihat risiko dan beban kerja tim.
