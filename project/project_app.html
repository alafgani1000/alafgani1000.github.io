Instalasi App

Berikut langkah-langkah untuk menginstal aplikasi ini dari GitHub:
  1. Klon repositori 
    git clone https://github.com/alafgani1000/project-app.git
cd project-app
  2. Instal Dependensi PHP 
    composer install
  3. Instal Dependensi JavaScript 
    npm install
# atau
yarn install
  4. Konfigurasi Aplikasi
    • File Environment: Salin file konfigurasi: 
      cp .env.example .env
    • Generate App Key: 
      php artisan key:generate
    • Konfigurasi Database: Buka file .env dan perbarui pengaturan database sesuai pengaturan lokal Anda: 
      DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=project_app
DB_USERNAME=root
DB_PASSWORD=
      Catatan: Pastikan Anda telah membuat database (contoh: project_app) di server MySQL sebelum melanjutkan.
  5. Pengaturan Database 
    php artisan migrate --seed
  6. Konfigurasi Email & Antrean (Queue)
    • Mail Driver: 
      MAIL_MAILER=smtp
MAIL_HOST=sandbox.smtp.mailtrap.io
MAIL_PORT=2525
MAIL_USERNAME=username_anda
MAIL_PASSWORD=password_anda
MAIL_ENCRYPTION=tls
    • Queue Driver: 
      QUEUE_CONNECTION=database
  7. Pengaturan Penyimpanan File 
    php artisan storage:link
  8. Menjalankan Aplikasi

    Buka dua terminal terpisah:

    • Terminal 1 (Backend) 
      php artisan serve
    • Terminal 2 (Frontend) 
      npm run dev
# atau
yarn dev
  9. Kredensial Default (Seeder) tersedia setelah proses seeding. Anda dapat mengubah atau menambah pengguna melalui fitur manajemen user di aplikasi.
  10. Informasi Tambahan
    • Queue Worker: 
      php artisan queue:work
    • Production Build: 
      npm run build
# atau
yarn build

Panduan Pengguna

  1. Buat project baru lalu tentukan timeline dan anggota tim.
